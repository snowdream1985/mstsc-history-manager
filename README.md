# 远程桌面历史记录管理工具（RemoteDesktopLog）

一个管理 Windows 远程桌面连接（mstsc）"计算机"下拉历史记录的桌面小工具。
查看、删除、排序、添加、备份，并清理与之关联的用户名提示、证书指纹和已保存的凭据。

## 为什么需要它

Windows 远程桌面连接会把连过的服务器记在下拉列表里，但系统**没有提供任何管理界面**，时间一长会遇到这些问题：

- 🔀 **列表被污染**：frp / SSH 隧道等场景产生大量 `127.0.0.1:随机端口` 的临时记录，把常用服务器越挤越靠后
- 🗑️ **删不干净**：想删某条记录，只能手动改注册表，而且数据分散在**三个位置**（下拉列表、每服务器的用户名提示与证书指纹、凭据管理器里保存的密码），普通用户根本理不清
- 👻 **残留垃圾**：下拉里的记录早就没了，注册表和凭据管理器里却还留着一堆"孤儿"数据
- 📦 **无法迁移**：换了电脑，常用服务器列表只能一台台重新连

本工具把这三处数据关联合在一起，提供一站式的图形化管理。

## 功能特性

| 功能 | 说明 |
|------|------|
| 📋 **总览所有记录** | 表格展示每条记录及其关联信息：记住的用户名、证书指纹、已存凭据，一目了然 |
| 🗑️ **灵活删除** | 单条 / 多选 / 全选删除，可勾选"同时清除用户名提示、证书指纹和已存凭据"（默认勾选） |
| 🎯 **通配符批量删** | 输入 `127.0.0.1:*` 之类的模式，实时预览匹配结果，一键清理隧道临时记录 |
| 👻 **残留清理** | 自动找出已不在下拉中、却仍残留在注册表里的 Servers 子键，一键清除（可连带删凭据） |
| ➕ **添加与排序** | 手动添加服务器到下拉顶部（自动去重），上移/下移调整顺序，把常用机器固定在最前 |
| 💾 **备份与迁移** | 导出列表为 JSON 文件；导入时可选"替换"或"合并"，换电脑一键恢复 |
| 🚀 **双击直连** | 双击记录或点"连接"，直接启动 mstsc 并预填服务器，省去打开远程桌面再选的步骤 |
| 🛡️ **写入防护** | 自动检测正在运行的 mstsc（它退出时会用旧数据覆盖你的修改），提醒关闭后再写入 |

## 界面概览

```
┌────────────────────────────────────────────────────────────────┐
│ 刷新 │ 添加 │ 删除 │ 批量删除 │ 上移 │ 下移 │ 导出 │ 导入 │ 连接 │   ← 工具栏
├────────────────────────────────────────────────────────────────┤
│ [MRU 历史记录] [Servers 残留清理]                               │   ← 两个标签页
│ ┌────────────────────────────────────────────────────────────┐ │
│ │ 序号 │ 服务器            │ 用户名提示      │ 证书指纹 │ 已存凭据│ │
│ │  1   │ hp               │ QHTF\wmgang    │   有    │   有   │ │
│ │  2   │ 127.0.0.1:65435  │                │   —     │   —    │ │
│ │  3   │ tx.example.com   │ CORP\admin     │   有    │   有   │ │
│ │ ...  │ ...              │ ...            │  ...    │  ...   │ │
│ └────────────────────────────────────────────────────────────┘ │
├────────────────────────────────────────────────────────────────┤
│ 共 10 条记录，残留 5 条              ⚠ 检测到 mstsc 正在运行… │   ← 状态栏
└────────────────────────────────────────────────────────────────┘
```

- **MRU 历史记录**：即 mstsc 下拉列表的内容，行顺序与下拉顺序完全一致
- **Servers 残留清理**：已不在下拉中、但注册表仍有残留数据的服务器条目
- **状态栏右侧**：实时监控 mstsc 进程，运行时红字警示（见下文"重要注意事项"）

## 使用指南

### 查看记录

打开工具即自动加载。每行显示：

- **服务器**：下拉中的原始内容（可能带端口，如 `192.168.1.1:3390`）
- **用户名提示**：连接该服务器时自动填充的用户名（来自注册表 `Servers` 子键）
- **证书指纹**：是否已信任过该服务器的证书（"不再询问"）
- **已存凭据**：凭据管理器中是否保存了该服务器的密码

点击工具栏 **刷新** 可随时重新读取（比如刚用 mstsc 连过新机器之后）。

### 删除记录

1. 选中一行或多行（`Ctrl`/`Shift` 多选，`Ctrl+A` 全选）
2. 点 **删除** 按钮（或按 `Del` 键、右键菜单）
3. 确认对话框中有一个默认勾选的选项：
   > ☑ 同时清除这些服务器的用户名提示、证书指纹和已保存的凭据
   - **保持勾选**（推荐）：彻底删除该服务器在你电脑上的一切痕迹
   - **取消勾选**：只从下拉列表移除，下次连接时用户名和密码仍然自动填充

### 通配符批量删除（清理隧道记录）

点 **批量删除**，输入通配符模式，下方实时显示"匹配 X 条记录"及明细，确认无误后点删除。

| 通配符 | 含义 | 示例 | 匹配 |
|--------|------|------|------|
| `*` | 任意长度任意字符 | `127.0.0.1:*` | 所有本机隧道端口记录 |
| `?` | 恰好一个字符 | `192.168.1.??` | `192.168.1.10` ~ `.99` 等 |
| 其他字符 | 原样匹配（不区分大小写） | `*.example.com` | 该域名下所有主机 |

### 清理残留数据

切换到 **Servers 残留清理** 标签页，列出所有"下拉里已没有、注册表却还在"的条目。
可 **删除选中** 或 **全部清除**；底部复选框"同时删除已保存的凭据"默认勾选。

### 添加服务器

点 **添加**，输入服务器地址（可带端口，如 `fileserver` 或 `10.0.0.8:3389`）。
新记录插入下拉**顶部**；若已存在同名记录，则提升到顶部而不会重复——与 mstsc 自身行为一致。

### 调整顺序

选中一行，点 **上移** / **下移**（第一行不能再上移，末行不能再下移）。
行顺序即 mstsc 下拉中的显示顺序，把常用服务器移到最前，就不会再被临时记录挤下去。

> 注：本工具不限制记录条数；mstsc 下拉本身的显示上限由 Windows 决定。

### 导出与导入（备份 / 换机迁移）

- **导出**：把当前列表存为 JSON 文件，格式简洁可读：
  ```json
  {
    "version": 1,
    "exportedAt": "2026-10-22T12:00:00+08:00",
    "servers": [ "hp", "minipc", "tx.example.com" ]
  }
  ```
- **导入**：选择备份文件后二选一：
  - **替换当前列表**：清空现有内容，完全按备份恢复
  - **合并到当前列表**：现有顺序不变，备份中的新记录追加到末尾

> 备份只包含服务器名称列表，**不包含**用户名、密码等敏感信息。

### 直接连接

双击任意记录（或选中后点 **连接** / 右键"连接"），相当于执行 `mstsc /v:服务器`，远程桌面窗口直接弹出并预填好地址。

### 快捷键

| 按键 | 作用 |
|------|------|
| 双击行 | 启动 mstsc 连接该服务器 |
| `Del` | 删除选中记录 |
| `Ctrl + C` | 复制选中的服务器名到剪贴板 |
| `Ctrl + A` | 全选 |

## 重要注意事项

### ⚠️ 修改前请先关闭远程桌面窗口

mstsc 在**退出时**会把内存中的旧历史列表回写注册表——如果在它开着的时候修改，你的修改会被它覆盖。因此：

- 状态栏实时监测 mstsc 进程，运行时显示红色警示
- 每次写入前工具会再次检测，发现 mstsc 在运行会弹出提示，关闭后点"重试"即可
- 写入后工具还会重新读取校验，不一致会给出警告

### 其他说明

- **只影响当前 Windows 用户**：历史记录存放在 `HKEY_CURRENT_USER` 下，各用户互不影响，**无需管理员权限**即可运行
- **删除凭据的后果**：清除某服务器的已存凭据后，下次连接需要重新输入密码（如勾选"记住我"会再次保存）
- **数据来源**：所有信息读取自注册表和 Windows 凭据管理器，本工具不记录、不上传任何数据

## 数据存储位置（进阶参考）

| 数据 | 位置 |
|------|------|
| 下拉列表 | 注册表 `HKCU\Software\Microsoft\Terminal Server Client\Default`，值 `MRU0`、`MRU1`…（MRU0 显示在最顶部） |
| 用户名提示 / 证书指纹 | 注册表 `HKCU\Software\Microsoft\Terminal Server Client\Servers\<服务器名>` 下的 `UsernameHint`、`CertHash` |
| 保存的密码 | Windows 凭据管理器 → Windows 凭据 → `TERMSRV/<服务器名>`（域密码类型） |

本工具的所有操作本质上就是对这三处的读写，你也可以用 `regedit` 和"凭据管理器"手动核对工具的每一次修改。

## 系统要求

- Windows 10 / 11（64 位）
- [.NET 8 桌面运行时](https://dotnet.microsoft.com/download/dotnet/8.0)（x64，Desktop Runtime）

直接运行：`RemoteDesktopLog\bin\Debug\net8.0-windows\RemoteDesktopLog.exe`

## 从源码构建

需要 .NET 8 SDK 或 Visual Studio 2022：

```bash
git clone <仓库地址>
cd RemoteDesktopLog
dotnet build RemoteDesktopLog.sln
```

项目结构：

```
RemoteDesktopLog.sln
├─ RemoteDesktopLog.Core      # 核心逻辑类库（无 UI 依赖，可独立复用/测试）
│   ├─ Models/                #   数据模型（MRU 条目、残留条目、备份格式）
│   └─ Services/              #   注册表读写、凭据 P/Invoke、通配符、备份、进程防护
└─ RemoteDesktopLog           # WinForms 界面
    ├─ MainForm.cs            #   主窗体（双标签页 + 工具栏 + 状态栏）
    └─ Forms/                 #   删除确认 / 添加 / 批量删除 / 导入方式 对话框
```

设计要点：

- **Core 与 UI 完全分离**：所有注册表、凭据、备份逻辑都在 Core 类库中，将来可复用出命令行版本
- **统一写路径**：所有 MRU 修改（删/增/排序/导入）收口为"删除全部旧值 → 连续重写 MRU0..n"，一步完成重排与清理，杜绝编号空洞
- **凭据处理**：通过 `CredEnumerate` / `CredDelete` P/Invoke 操作（TERMSRV 凭据为域密码类型），而非解析 `cmdkey` 的本地化文本输出；工具只枚举目标名和删除，**从不读取密码内容**

## 隐私与安全

- ✅ 纯本地运行，无任何网络请求，不收集、不上传任何数据
- ✅ 不读取凭据内容，仅检测目标是否存在、按你的指令删除
- ✅ 所有修改均可通过 `regedit` 和"凭据管理器"独立验证
